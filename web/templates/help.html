Help & Instructions

📚 Quick Start

  1. Design certificate in Canva with your branding
  2. Export to Google Drive as PPTX file
  3. Open in Google Slides and add {{Placeholder}} text
  4. Get Template ID from Google Slides URL
  5. Create CSV file with participant data
  6. Upload to this app and click Generate
  7. Download from Drive in the output folder

🎨 Designing Your Template (Canva)

Start by creating your certificate design in Canva:

  • Add your logo, borders, and styling
  • Include text like "Certificate of Completion"
  • Leave space for participant name and details
  • Export as PPTX (not PNG or PDF)

🔗 Prepare Template in Google Slides

  1. Upload your PPTX to Google Drive
  2. Right-click → Open with → Google Slides
  3. Google auto-converts it for you
  4. Click on each text field that needs dynamic content
  5. Replace with placeholders like: {{Name}}, {{Email}}, etc.
  6. Important: Placeholders must be created in Google Slides, not Canva

Placeholder Syntax

Use double curly braces around field names:

  • {{Name}} → Replaced with participant name
  • {{Email}} → Replaced with email address
  • {{Date}} → Replaced with date
  • {{Any Custom Field}} → Matches CSV column

📋 CSV File Format

Create a CSV (Excel) file with your participant data:

Name,Email,Date,Event
John Doe,john@example.com,April 13 2024,Spring Conference
Jane Smith,jane@example.com,April 13 2024,Spring Conference
Bob Johnson,bob@example.com,April 13 2024,Spring Conference

Rules:

  • First row must be column headers
  • Column names must exactly match placeholder names (case-sensitive)
  • Each row = one certificate to generate
  • Use Name column for PDF filename

🎯 Get Your Template ID

  1. Open your template in Google Slides
  2. Look at the URL in address bar:
  3. https://docs.google.com/presentation/d/1abc2def3ghi4jkl5mno6pqr/edit
  4. Copy the bold part (26+ character ID)
  5. Paste into the "Template ID" field on this site

⚡ Generate Certificates

  1. Click "Generate Certificates" button on dashboard
  2. Upload your CSV file
  3. Paste your template ID
  4. Optional: Change output folder name (default: "Certificate Generator")
  5. Click "Generate"
  6. Wait for completion (takes ~15-30 seconds per certificate)
  7. Certificates automatically appear in your Google Drive folder

Processing Time

  • 10 certificates: 3-5 minutes
  • 50 certificates: 15-25 minutes
  • 100 certificates: 30-50 minutes

💾 Download Certificates

After generation completes:

  1. Open Google Drive
  2. Navigate to the output folder (e.g., "Certificate Generator")
  3. Each PDF file is named: [Participant Name].pdf
  4. Download or share directly from Drive

🔒 Privacy & Security

  • ✅ You sign in with your own Google account
  • ✅ Certificates are saved to your Drive, not our servers
  • ✅ We never store your CSV data
  • ✅ Your credentials are only used for Google Drive access
  • ✅ All data stays within your Google account

❓ Common Questions

Q: Can I use different placeholder names?

Yes! Just match your CSV column names to your template placeholders exactly.

Q: What if I have extra columns in CSV?

Extra columns are ignored. Only columns matching placeholders are used.

Q: Can I add images to certificates?

Yes! Add images to your Canva template before exporting. They'll appear in all certificates.

Q: How many certificates can I generate?

You can generate 100s or 1000s. Processing time depends on quantity and your internet speed.

Q: Can I edit certificates after generation?

Yes! PDFs are in your Drive, so you can download and edit them.

Q: What if generation fails?

Check the error message for details. Common issues:

  • Template ID is incorrect
  • CSV column doesn't match placeholder name
  • Connection issue (wait and try again)

Q: Can I use this for multiple events?

Yes! Create one template per event/type, then reuse with different CSV files.

🆘 Troubleshooting

Error: "Invalid template ID"

  • Check ID is 26+ characters
  • Verify it's from Google Slides (not Docs or Sheets)
  • Try copying the ID again from the URL

Error: "Missing CSV columns"

  • Check CSV column names match placeholders exactly (case-sensitive)
  • Example: {{Name}} requires "Name" column in CSV
  • Example: {{email}} requires "email" column (lowercase)

Certificates not appearing in Drive

  • Check the output folder name (default: "Certificate Generator")
  • Refresh Google Drive (F5)
  • Check generation completed successfully

Generation is slow

  • This is normal! Each certificate takes 15-30 seconds
  • Internet speed affects processing
  • Try during off-peak hours
