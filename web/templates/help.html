Help & Instructions

📚 Quick Start

  1. Add editable {% raw %}{{Placeholder}}{% endraw %} text directly to the certificate slide.
  2. Under Certificate template, choose Upload from computer (.ppt or .pptx) or Google Slides.
  3. Choose your recipient data and click Generate Certificates. Use Test (First N) for a sample.
  4. Click Open output folder in the results to find your PDFs.

🎨 Designing Your Template (Canva)

Start by creating your certificate design in Canva:

  • Add your logo, borders, and styling
  • Include text like "Certificate of Completion"
  • Leave space for participant name and details
  • Export as PPTX and open it in PowerPoint to verify the editable text boxes

Prepare Your Template

  1. Open your certificate design in PowerPoint or Google Slides.
  2. Use editable text boxes for placeholders such as {% raw %}{{Name}}{% endraw %} and {% raw %}{{Email}}{% endraw %}.
  3. For a PowerPoint file, choose Upload from computer on the dashboard. The app converts it to Google Slides when generation starts.

Placeholder Syntax

Use double curly braces around field names:

  • {% raw %}{{Name}}{% endraw %} → Replaced with participant name
  • {% raw %}{{Email}}{% endraw %} → Replaced with email address
  • {% raw %}{{Date}}{% endraw %} → Replaced with date
  • {% raw %}{{Any Custom Field}}{% endraw %} → Matches a recipient column

📋 Recipient Data

Use Google Drive to select a CSV or a Google Sheets tab. Use CSV Upload to upload a local CSV, Excel, TSV, TXT, ODS, JSON, or JSONL file. Uploaded Excel workbooks use the first worksheet.

This CSV supplies values for a certificate template.

Participant Name,Email,Date,Event
John Doe,john@example.com,April 13 2024,Spring Conference
Jane Smith,jane@example.com,April 13 2024,Spring Conference
Bob Johnson,bob@example.com,April 13 2024,Spring Conference

Column Matching

  • First row must be column headers
  • Match column names to placeholder names regardless of capitalization. {% raw %}{{Name}}{% endraw %} uses Participant Name when there is no Name column.
  • Each row = one certificate to generate
  • PDF filenames default to Name or Participant Name.

Find a Google Slides Template ID

  1. Open the native presentation in Google Slides.
  2. Copy its address, such as https://docs.google.com/presentation/d/1abc2def3ghi4jkl5mno6pqr/edit.
  3. On the dashboard, choose Google Slides and paste the full link or the highlighted ID.

⚡ Generate Certificates

  1. Choose the recipient data and template. Select a filename field if you want to use a different column.
  2. Enter an output folder name or use Certificate Generator. New batches use a writable folder at the top level of My Drive.
  3. To organize PDFs, select Group certificates by column. Rows with blank group values go in the main output folder.
  4. Click Generate Certificates for every row, or use Test (First N) and Start Test for a sample in a folder ending in (TEST).

💾 Download Certificates

Check Created PDFs in the results, then click Open output folder to download or share the saved PDFs from Drive.

Recover an Interrupted Batch

  1. Select the batch under Recover a generation batch and click Check Batch Status.
  2. Use Resume Batch with the original data and settings. After a reload, reselect the original recipient data and upload the PowerPoint again if the app asks for it.
  3. If Drive blocks the folder after saving some PDFs, restore write access and resume. If zero PDFs were saved to a blocked destination, start a new batch so the app can choose a writable folder.

The app stores PDFs and batch recovery state in the signed-in account's Drive.

❓ Common Questions

Q: Can I use different placeholder names?

Yes. Match your CSV column names to your template placeholders.

Q: What if I have extra columns in CSV?

Extra columns can supply PDF filenames or group subfolders.

Q: Can I add images to certificates?

Yes! Add images to your Canva template before exporting. They'll appear in all certificates.

Q: What if generation fails?

Check the error message for details. Common issues:

  • Template ID is incorrect
  • CSV column doesn't match placeholder name
  • Connection issue (wait and try again)

Q: Can I use this for multiple events?

Yes! Create one template per event/type, then reuse with different CSV files.

🆘 Troubleshooting

Google Slides Template Link

  • Paste the full presentation link or choose the presentation using Select Template from Drive.
  • Check that the signed-in account can read and copy the presentation.

Missing Recipient Columns

  • Check that the column names match the placeholders. {% raw %}{{Name}}{% endraw %} can use Participant Name when Name is absent.
  • Matching ignores case, so {% raw %}{{email}}{% endraw %} works with the Email column.

Missing PowerPoint Placeholders After Conversion

  • In PowerPoint, type the missing field in a regular text box directly on the certificate slide, then save and upload the file again.
  • Use Test (First N) to check the placeholder and layout in the exported PDF.
